# Zaaltool

Zaalhockey tactiekbord van AMHC Apeldoorn.

Open de tool: https://nivigon.github.io/zaaltool/

- Coachbord: opstellingen, patronen, tekenen en animaties
- Zaalhockey voor mij: inhoud per niveau (beginner, gemiddeld, gevorderd)

Oefeningen worden opgeslagen in de browser van het apparaat waarop je werkt.
